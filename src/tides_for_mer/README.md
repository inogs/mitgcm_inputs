# Tidal Forcing Generator for MITgcm

This repository contains scripts that generate tidal boundary forcing files (binary) for MITgcm.

## Requirements:
	- TPXO10-atlas-v2 tidal atlas (binary format, August 2024 release)
	- pyTMD 2.2.8 

> **Note:** TPXO10-atlas-v2 is not included in this repository.  
> Download it separately and update the data path in the configuration file.

Install pyTMD:

```bash
pip install pyTMD==2.2.8
```

## Generating the files

1. Edit `tides_config_new.json` to set the following options:

   | Key | Description |
   | --- | --- |
   | `path_results` | Path where the results will be saved. |
   | `path_tide_hc_data` | Path to the TPXO10-atlas-v2 atlas. |
   | `path_grid` | Path to the MITgcm grid. The scripts will search for a file named `MIT_static.nc`, which is a MER ST file. |
   | `tide_model` | Version of the tide model in use: `TPXO10-atlas-v2`. |
   | `constituents` | List of tidal constituents to consider. |
   | `boundaries` | Open boundaries of the model where tidal forcing will be applied. |
   | `grid_dims` | Model dimensions, `[depth, latitude, longitude]`. |
   | `corrections_datetime` | Simulation start date and time. Used for the signal corrections. |
   | `binary_data_endianness` | Endianness of the MITgcm binary files produced as output. |

2. Run `set_bc_grid.py` and `set_bc_tides_static.py` for each model domain.

   - **`set_bc_grid.py`** — Generates the boundary grid file from the model grid file (`MIT_static.nc`).
     - If `AngleCS` and/or `AngleSN` are not present in the grid file, they are set to:
       - `AngleCS = np.ones((ny, nx))`
       - `AngleSN = np.zeros((ny, nx))`
     - Output: a boundary file containing the coordinates of the boundary nodes for each open boundary.

   - **`set_bc_tides_static.py`** — Reads the depth-integrated velocity transport tidal atlas data using pyTMD and interpolates it onto the model boundaries (generated by `set_bc_grid.py`). A second interpolation (`intp_line_safe`) is then applied within the same script.
     - The `intp_line_safe` interpolation fills NaNs along the boundary for each constituent, or substitutes them with `0` where `depth_bc = 0` (land).
     - Output: amplitudes and phases of the depth-integrated transports `u` and `v`, with dimensions `(n_points, n_constituents)` for each open boundary. Here `n_points` is the number of nodes along the boundary — `nx` for boundaries running east–west (longitude direction) or `ny` for boundaries running north–south (latitude direction). Results are saved as `.npy` files.

3. Run `set_bc_tides_corrections.py` for each simulation start time and for each model domain. This script generates the tidal signal for MITgcm by applying corrections to the static data produced by `set_bc_tides_static.py`.

   The script:

   - Loads the static tidal signal calculated by `set_bc_tides_static.py`.
   - Retrieves the constituent parameters for each constituent using pyTMD.
   - Loops over constituents and applies the corrections:
     - Nodal corrections (for the simulation start time) and astronomical argument correction.
     - Transforms depth-integrated transports into velocities by dividing by the depth.
     - Rotates the velocities into the model grid.
     - Applies the MITgcm reference time correction (using the simulation start time) and converts phases to seconds for MITgcm.

   **Output:** corrected amplitudes and phases of the velocities `u` and `v`, with dimensions `(n_points, n_constituents)` for each open boundary. Here `n_points` is the number of nodes along the boundary — `nx` for boundaries running east–west (longitude direction) or `ny` for boundaries running north–south (latitude direction). Results are saved as `.npy` files and as MITgcm binary files (with transposed dimensions).
